# Fund Trend and Risk Analyzer

这是一个使用 Python 制作的基金趋势与风险分析工具。

## 项目功能

- 输入基金名称
- 输入多天基金净值
- 分析基金总涨跌幅
- 分析最近一天涨跌幅
- 判断基金趋势
- 计算最大回撤
- 计算平均波动幅度
- 判断风险等级
- 生成完整分析报告
- 保存报告到 txt 文件

## 当前版本

V1：手动输入基金净值数据，自动生成基金涨跌和风险分析报告。
